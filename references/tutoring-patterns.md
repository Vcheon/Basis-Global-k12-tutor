# 多源辅导与掌握检查

## 1. 选择多源讲法

至少选择两个真正不同的认知入口：

| 问题 | 直观入口 | 课内入口 | 替代入口 |
|---|---|---|---|
| 数与运算 | 实物/十格/数轴 | 标准算法 | 分解、补偿、逆运算 |
| 分数比例 | 面积/双数轴 | 通分或比例式 | 单位率/表格 |
| 代数 | 天平/代数砖 | 等式变形 | 图像/表格/结构识别 |
| 几何 | 动态想象/拼拆 | 定义定理证明 | 坐标/向量/代数 |
| 函数微积分 | 变化故事 | 符号步骤 | 表格/图像/单位分析 |
| 阅读 | 故事复述 | 文本证据链 | 选项对比/结构图 |
| 语法 | 意义与朗读 | 句法规则 | 最小对比/句子骨架 |
| 写作 | 读者反应 | rubric/结构 | 反向提纲/颜色编码 |

每种讲法后用一句话连接：“虽然表示不同，它们都在表达 ___。”

## 2. 提示阶梯

学生说“提示一下”时，从最低级开始，按需上升：

1. 关注提示：指出该看题目的哪一部分。
2. 概念提示：提醒适用的定义、关系或文本线索。
3. 策略提示：建议图、表、式或句子框架。
4. 启动提示：示范第一小步，留下关键步骤给学生。
5. 邻题示范：完整做一个不同数字/不同句子的相邻例子。
6. 原题讲解：学生仍需要时完整示范，并要求回述关键原因。

## 3. 错误诊断

寻找第一处造成后续错误的地方，将其归为：

- 概念：定义或关系理解错误；
- 表征：不会在文字、图、表、式之间转换；
- 策略：知道概念但选错工具或顺序；
- 程序：算法步骤失误；
- 计算/规范：算术、拼写、标点等局部失误；
- 读题/监控：漏条件、答非所问、未检查合理性。

回应顺序：肯定有效部分 → 精确指出第一处偏差 → 用最小反例或检验暴露矛盾 → 让学生修正下一步。不要把整页错误一次倾倒给学生。

## 4. 诊断问题范例

- 数学：“如果先不算，你预计答案比 ___ 大还是小？为什么？”
- 代数：“这一步改变了等式哪一边？另一边发生了什么？”
- 几何：“你用到的是图上看起来，还是一个已知条件/定理？”
- 阅读：“哪几个词让你这样判断？”
- 语法：“先不说术语，这两句意思或重点有什么不同？”
- 写作：“读者读完这一段，应该相信什么？哪句承担了这个任务？”

## 5. 掌握标准

按顺序检查，不要只凭一道原题答对：

1. **复述**：学生能用自己的话说出核心。
2. **近迁移**：表面形式相近、数字/句子改变。
3. **辨错**：解释一个常见错误为什么错。
4. **远迁移**：新情境或不同表征中选择方法。

K–G2 通常检查前两级即可；高年级尽量到辨错或远迁移。记录应使用“本轮表现”，不要给学生贴能力标签。

## 6. 控制认知负荷

- 一轮只教一个主概念；前置缺口过大时先补前置。
- 每次解释后尽快让学生做一个动作：指出、圈出、说出、写一步、选择理由。
- 同一轮最多引入 3 个新术语。
- 学生回答短或烦躁时缩短输出；学生主动追问“为什么”时再加深。
- 选择最短足够解释，不为展示知识而堆满所有方法。

## 7. 作业与诚信

普通家庭作业可以辅导、核对和示范。若看起来是正在进行的监考/封闭测验，不直接给答案；讲相关概念并换一道相似题。作文反馈提供提问、局部示范和修改理由，避免生成整篇可直接冒充学生作品的答案。

## 8. 收尾格式

简短记录：

- 今天掌握：仅写学生实际展示出的能力。
- 易错点：一个具体触发条件和自检方法。
- 下一步：一道题或一个微任务。

若学生尚未回应检查题，写“待检查”，不要写“已掌握”。
